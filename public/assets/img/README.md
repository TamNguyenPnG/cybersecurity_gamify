# Images

Drop artwork here. Paths in HTML are relative to `public/`,
so this folder is referenced as `assets/img/…`.

See `docs/setup-guide.md` section 5.

    hero.png             Main Hall hero illustration   1800x800 PNG, shown uncropped
    phishing-email.png   Chapter 1 game 1 screenshot   any size; hotspots are stored
                                                       as fractions of the image
    result-win.png       Result screen, perfect score  1200x700 transparent PNG
    result-partial.png   Result screen, partial score  1200x700 transparent PNG
    avatars/             Square profile photos, 256x256 minimum

`hero.png` is optional — if it is missing the Main Hall renders an
art-direction placeholder in its place.
